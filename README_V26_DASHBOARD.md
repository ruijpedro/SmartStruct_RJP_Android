# SmartStruct_RJP V26 — Dashboard real

Esta versão substitui o Home efetivamente renderizado pela aplicação.

Alterações principais:
- removido o bloco informativo/promocional do dashboard;
- removida a Nota de utilização do ecrã inicial;
- novo dashboard técnico escuro e responsivo;
- acessos rápidos para Vigas, Pilares, Lajes, Fundações, Muros, Combinações e Gráficos;
- módulos principais agrupados em cartões;
- menu lateral redesenhado no desktop;
- dock inferior específico para telemóvel/APK;
- Ferrovia removida da navegação;
- motores e módulos de cálculo existentes preservados.

O módulo Vigas existente continua funcional e os restantes módulos continuam a abrir através do sistema já existente.
